# Migration vers Karned Agency

Le POC Todo est transféré vers `karned-agency/arclith-POC-todo` afin que le
tutoriel public et son code exécutable restent rattachés à la même source de
vérité que le framework. Les métadonnées pointent vers le nouveau dépôt et le
domaine documentaire `https://arclith.karned.bzh/`.

`main`, afin que le POC documentaire reste réellement reproductible.
