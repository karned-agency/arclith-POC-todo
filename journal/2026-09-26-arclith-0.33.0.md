# Alignement sur Arclith 0.33.0

Le POC Todo exige désormais `arclith>=0.33.0` et verrouille la version publiée
sur PyPI. Le tutoriel exécutable valide ainsi la release issue du dépôt migré
`karned-agency/arclith` plutôt qu'une ancienne version du framework.

Arclith 0.33.0 valide strictement les mappings de secrets au chargement. La
configuration MongoDB déclare donc explicitement `uri: null` comme point
d'injection : le profil mémoire des tests reste autonome, tandis qu'une
opération MongoDB sans secret résolu échoue toujours avant toute connexion.

Les dépendances LangGraph respectent désormais `TODO_LIST_CONFIG_DIR`, comme
l'entrypoint principal. Pytest prépare cette configuration mémoire avant la
collecte afin qu'aucun adapter MongoDB ou LangSmith ne soit initialisé pendant
les tests.
